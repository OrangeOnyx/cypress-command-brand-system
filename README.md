# Cypress Command brand system

The approved Cypress Command 04C identity system and its static website starter.

## Repository layout

- `brand-system/` — v1.0.1 brand assets, standards, vectors, documents, presentation, print artwork, tokens, fonts, launch instructions, and original reference material.
- `website-starter/` — upload-ready static site. Its contents—not the enclosing folder—belong at the public site root.
- `source/` — deterministic build and verification scripts retained for maintenance. They were developed for the accompanying Windows/Codex environment; inspect paths and dependencies before rerunning elsewhere.
