# Cypress Command Word templates

These templates use the final approved rounded 04C logo, Cypress and Moss accents, Fraunces headings, and Inter body text. The logo is embedded artwork; all letter, proposal, report, and table content remains editable.

The confirmed website is **cypresscommand.com** and appears in the letterhead footer. Name, role, email, phone, and other unconfirmed fields remain placeholders. No email alias has been inferred from the domain.

## Choose a starting file

- **Cypress_Command_Letterhead.dotx** creates a one-page business letter with recipient, subject, body, and sender placeholders.
- **Cypress_Command_Proposal.dotx** creates a three-page project proposal covering the recommendation, scope, deliverables, fees, schedule, and next step. It is not a services agreement or legal contract.
- **Cypress_Command_Operating_Report.dotx** creates a three-page recurring operating report with performance, workstreams, issues, decisions, actions, and source records. No business results or metrics have been supplied or invented.

Open a DOTX to create a new document, then save the new document as DOCX under a project-specific filename. DOCX counterparts are also supplied for applications that do not support Word templates. Duplicate those before editing.

## Fill and issue

1. Replace every bracketed field. Search for `[` before issuing a finished document. Delete any unused rows, sections, and attachment references.
2. Replace the letter title with its actual subject. Replace project and business unit labels in proposals and reports. Confirm recipient, legal entity, contact information, period, amounts, tax treatment, and dates.
3. Use the named styles instead of manual formatting. After replacing a green prompt paragraph, apply **Normal** and remove the **CC Placeholder** character style so the final prose is Charcoal. In Word, selecting the paragraph and pressing Ctrl+Space removes character formatting while preserving its paragraph style.
4. Keep the logo proportional. Edit the page header only if changing approved logo variants. Every header uses a 2.6-inch-wide horizontal lockup including its clear space, equivalent to 66.04 mm and above the 65 mm minimum. Do not stretch or crop it.
5. Add or remove table rows as needed. Header rows repeat automatically, body rows can grow, and rows stay together. Page breaks establish useful starting sections; adjust them when the final content changes.
6. Use Ctrl+A then F9 to update body fields. Page numbers in the footer update when Word repaginates or exports. Review all pages after editing, and export a PDF for distribution when editability is not required.

## Styles and type

| Style | Role |
| --- | --- |
| Title | Fraunces 28 pt document title |
| Heading 1 | Fraunces 19 pt section heading |
| Heading 2 | Inter 12 pt bold subheading |
| Subtitle | Inter 13 pt project or subject label |
| Normal | Inter 11.5 pt sustained prose |
| CC Metadata | Inter 9.5 pt document reference and period |
| CC Table | Inter 10.5 pt editable table content |
| CC Small | Inter 9.5 pt supporting notes |
| CC Footer | Inter 8.5 pt footer and page numbering |
| CC Placeholder | Moss character style for removable prompts |

The Word family names are **Cypress Inter** and **Cypress Fraunces**. These are static desktop instances derived from the approved supporting fonts, not replacement typefaces. Regular Inter, Bold Inter, and Regular Fraunces TTF payloads are embedded in each DOCX and DOTX. The font files and their OFL licenses are included in the parent package. No fonts were installed on this computer.

Font support varies by application. Microsoft Word was used for final visual verification. Some online editors and non-Microsoft viewers ignore embedded fonts; install the supplied desktop fonts yourself if your application requires it, or use an exported PDF for consistent distribution. The supplied font subsets cover the templates' Latin text; check every glyph if adding other scripts or unusual symbols.

## Document setup

US Letter portrait, 8.5 by 11 inches; 0.8-inch left and right margins; 11.5 pt body; native Word page-number fields; editable tables; no macros; no external image or font links. The document logo is the exact supplied PNG with the standard 04C proportions and center square retained.

These are reusable working templates. Their empty fields are intentional, not completed business records. They have not been sent to clients, installed as Office defaults, or uploaded to document services.
