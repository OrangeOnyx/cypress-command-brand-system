# Cypress Command presentation templates

Use the `.potx` to start a new presentation, or duplicate the `.pptx` and edit the copy. Both contain the same eight reusable 16:9 slides. Duplicate the relevant example slide to preserve its layout. These are fully editable starter slides, not a custom Slide Master layout gallery.

## Fonts

Install the supplied `Cypress Inter` and `Cypress Fraunces` desktop TTF files from `../fonts/desktop/` before editing or presenting in PowerPoint. Close and reopen PowerPoint after installation. No fonts were installed on your computer as part of this delivery. These desktop names distinguish the package's static instances from variable web fonts.

The deck declares these fonts but does not embed them. The PDF preview preserves the intended appearance without requiring font installation. It is an image-based visual reference, not the editable or accessible text source.

## Editing

- Replace every bracketed placeholder before presenting. Remove unused source/contact fields.
- The chart's Example A / B / C and values 1 / 2 / 3 are illustrative only. Use **Chart Design > Edit Data** to replace the embedded workbook values and labels. State the actual metric, units, reporting period and source.
- The table contains four blank body rows. Use **Table Layout** to enter values or add rows.
- For the case-study slide, replace the left frame and its placeholder label with an approved photograph. Add photo rights and evidence for claimed results in speaker notes.
- Keep the supplied logo images proportional. They are fixed brand artwork, separate from the editable content. Use the logo SVG masters in the full brand package when producing additional lockups or large-format output.
- Use Fraunces for display headings and Inter for supporting text and data. The wordmark is approved outlined artwork, not typed content.
- The PDF is a preview of these starter slides. Export a fresh PDF from your edited PowerPoint for actual distribution.

The closing slide includes the user-confirmed domain `cypresscommand.com`. This does not assert that the website is live or email is configured. The deck includes no invented company results, email address, phone number or title. The original approved logo suite is unchanged.
