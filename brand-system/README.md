# Cypress Command — approved brand system v1.0

This release finalizes the approved 04C design without changing the selected logo. It combines the rounded mark and outlined wordmark with the approved five-color palette and curated supporting system. Adam Abdalla is **Owner / Founder**, with a Lafayette mailing address, and confirmed purchase of **cypresscommand.com**. No website, DNS, mailbox, social account, or Office default was changed.

**Start with `index.html`** for the asset library, then `Brand_Standards.pdf` for the rules. Extract the complete package before opening local pages. `ROLLOUT.md` is the implementation checklist.

This is the current source of truth. It supersedes the earlier 04B package and the 04C adoption-review kit for new Cypress Command work; those originals remain preserved and unchanged.

## Use consistently

- Default logo: `logos/svg/cc-04c-horizontal-primary.svg`. Preserve its proportions, center square, and supplied clear space. Use the designated one-color, reverse, and micro assets instead of modifying the mark.
- Palette: Cypress `#1E4D3A`, Moss `#2F6B4E`, Amber `#D97706`, Charcoal `#0A1F16`, Bone `#F3EDE0`. Amber is a restrained accent; 04D-derived frames support the layout and never replace the logo.
- Type: Fraunces display, Inter body/UI, JetBrains Mono identifiers only. The wordmark is supplied artwork, not text to retype.
- Keep claims, metrics, project details, and contact information evidence-based. Replace or remove bracketed fields before external use.

## Before use

The name, role, domain, and mailing address are confirmed. **Email and phone remain unconfirmed** in `brand-config.json`; `info@cypresscommand.com` and `adam@cypresscommand.com` are planned addresses, not yet configured. Physical artwork is a vendor handoff, not a manufacturing guarantee. The business card includes bleed and is RGB; the chosen printer must confirm color conversion, output profile, trim, and proof. Signage dimensions, installation, material, safety, and embroidery stitch-outs require vendor review.

No assets were deployed, sent to vendors, installed into accounts, or automatically applied to Adam's other businesses or projects.
