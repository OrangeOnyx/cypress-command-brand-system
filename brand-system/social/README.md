# Social and screen assets

PNG exports are ready for placement at the listed pixel dimensions. Editable HTML sources are in `templates/` and load the exact local artwork/fonts. They contain no tracking or remote assets. Edit copy in the HTML, then export at its declared pixel size; ordinary browser Print produces a PDF rather than an exact-size social PNG.

| File | Dimensions | Intended use |
| --- | --- | --- |
| `avatar-512.png` | 512 × 512 | Profile/app image; check final circle/square mask |
| `og-default.png` | 1200 × 630 | Website sharing preview |
| `brand-square.png` | 1080 × 1080 | Square brand post |
| `brand-portrait.png` | 1080 × 1350 | Portrait brand post |
| `brand-story.png` | 1080 × 1920 | Full-height brand graphic |
| `announcement-square.png` | 1080 × 1080 | Reusable announcement; replace every bracketed field |
| `wide-banner-4x1.png` | 1584 × 396 | Wide profile/banner starting format |
| `wide-banner-3x1.png` | 1500 × 500 | Alternate wide banner starting format |
| `video-background.png` | 1920 × 1080 | Meeting background with a clear center |
| `desktop-wallpaper.png` | 3840 × 2160 | 4K screen background |

These are general aspect-ratio assets, not a promise of current platform specifications. Check each destination's crop, UI overlays, avatar overlap, and compression before publishing. Never stretch a logo to fill a crop. Keep the domain and contact details in profile fields rather than inventing handles. The confirmed website is `https://cypresscommand.com`.

The announcement is deliberately unfinished content. The other brand graphics carry only approved brand language, not fabricated company statistics or property imagery. Meeting software may mirror your own preview; check how recipients see it before manually flipping artwork.
